# seismic-sim

日本全国の地震動シミュレータと地震モニタ。

震源パラメータを与えると、気象庁の震度観測点 4,360 点と太平洋側の海底地震計
201 点における地震動を合成し、
リアルタイム震度の時系列・計測震度・緊急地震速報の発表列・余震活動・津波予報を
生成する。結果はブラウザ上の地震モニタで時系列に再生できる。

## できること

| | |
|---|---|
| **視覚モード** | 発震直後は震源周辺に寄って、揺れを検出した観測点の範囲を四角で囲む。第 1 報の発表でズームアウトして緊急地震速報の画面へ移り、P/S 波の広がりと観測点ごとのリアルタイム震度を見せる。揺れが収まると細分区域ごとの確定震度に切り替わり、続いて余震が発生する。津波警報は海岸線を警報種別の色で示す |
| **設定モード** | 地図をクリックして震源・規模・深さ・断層パラメータを指定し、その場で計算する。余震・津波・緊急地震速報の有無も切り替えられる |
| **地震情報** | 最大震度・震源地・マグニチュード・深さを表示。直近 5 件はクリックで再生でき、履歴は 15 件まで残る |

地震情報は気象庁と同じ順序で 3 段階に分けて出す。**震度速報**（発生から 90 秒。
震度だけで震源は「調査中」）、**震源に関する情報**（170 秒。震源・規模・深さが決まる）、
**震源・震度に関する情報**（260 秒。確定）。

観測点の表示は **震度の数字入りの円**・**PGA の色だけの円**（強震モニタ風の連続配色、
0.01〜1000 gal）・**津波の沿岸線だけ** の 3 つを凡例のスイッチで切り替えられる。
切り替えは地震の再生中も検知の段階も効き、選んだ側が保存される。

揺れているあいだは数字入りの円、地震情報（確定）では角の丸いタイルで出す。タイルは
地点ごとではなく**細分区域ごとに 1 つ**置き、重なるところは強い震度を残す。5弱・5強
などは記号を肩に小さく付ける（5⁻ 5⁺ 6⁻ 6⁺）。細分区域の塗りつぶしも同じ配色で、
地震情報の画面ではその上にタイルが載る。

**津波** に切り替えると観測点と震度の塗り分けを消し、津波予報区の沿岸線だけを出す。
発表前は予報区の縁を薄い灰色で置いておき、発表されるとその段の色に変わる。

### 海底地震計

太平洋側の海底には、日本海溝海底地震津波観測網 **S-net**（150 点）と南海トラフ
海底地震津波観測網 **DONET**（51 点）に相当する観測点を置いている。実際のケーブル
配置の座標は公開されていないため、海溝軸と陸棚外縁を結ぶ線の上に、担当区間と点数を
合わせて並べた近似（`tools/build_seafloor.py`）。海底では震度を発表しないので
タイルは付けず、揺れていないあいだは くすんだ黄緑の点で置き、揺れ出したところから
陸と同じ強震モニタの配色に移る。細分区域には属さないので、震度速報や地域の
塗り分けには出てこない。海のうねりが起こす脈動のぶん、常時微動は陸の 3 倍にしてある。

観測点は揺れていないときも常時微動を拾っており、その大きさは場所によって二桁ほど違う。
平常時の画面が一様な青ではなく、青のなかに緑や黄緑がまだらに混じるのはこのためで、
観測点ごとに決まった値として与えている（`web/js/util.js` の `ambientPGA`）。
軟弱地盤ほど微動が大きいものとして AVS30 で中央値をずらしている。

微動の大きさは一定ではない。交通も風も波も変わり続けるので、実際の画面は絶えず
ちらついて見える。観測点ごとの種と時刻から作った滑らかな雑音（ゆっくりした
0.45 Hz とやや速い 1.6 Hz の重ね合わせ）を中央値に掛けて、log10 で ±0.32 の幅で
揺らがせている。地震の再生を止めていても動き続ける。揺れているあいだは
実際の値のほうが大きいので、そちらが出る。

## 2 つの計算エンジン

同じ物理を、精度と速度の違う 2 通りで実装している。

**Python（高精度・オフライン）** — 確率論的地震動合成で 3 成分の加速度波形を作り、
気象庁告示どおりの手順で計測震度を算出する。1 シナリオあたり数分。
`scripts/run_scenario.py` で計算し、結果を JSON に書き出して再生する。

**JavaScript（簡易・その場で計算）** — 距離減衰式で震度分布を求め、走時表から
到達時刻を引く。設定モードで指定した震源を待たずに再生できる。

両者は震度分布と到達時刻で整合するよう較正してある。

## 物理モデル

### 走時 — `sim/velocity.py`

JMA2001 に準じた 1 次元速度構造（深さ 0〜700 km、Vp/Vs = 1.73）を薄層に分割し、
レイパラメータ p を掃引して走時曲線を作る。各層で

```
eta = sqrt(1/v² - p²)        鉛直スローネス
dX  = p · dz / eta           水平距離の増分
dT  = dz / (v² · eta)        走時の増分
```

を積み上げる。レイは `v(z) = 1/p` となる深さで反転する。上向き直達波と
下向き反転波の 2 つの枝を計算し、同じ震央距離に複数の到達がある場合は
最小走時（初動）を採る。速度の不連続は制御点間を線形補間して連続勾配に均し、
head wave を turning ray として取り込む。

深さ 10 km・震央距離 100 km で P 波 16.3 秒、S-P 時間 11.9 秒。

### 震源 — `sim/source.py`

モーメントマグニチュードから地震モーメント `M0 = 10^(1.5·Mw + 9.1)` [N·m] を求め、
断層面積は地殻内・スラブ内で入倉・三宅 (2001)、プレート間で Murotani et al. (2008)
系のスケーリング則による。幅は地震発生層の厚さで頭打ちにする。断層面は走向・傾斜を
持つ矩形として小断層に分割し、破壊開始点からの距離を破壊伝播速度（0.72 Vs）で
割った時間を各小断層の破壊時刻とする。

### 地震動の合成 — `sim/stochastic.py`

Boore の stochastic method。各小断層について

```
A(f) = C · S(f) · G(R) · exp(−π f R / (Q(f) v)) · Amp_site(f) · exp(−π κ f)
```

- `S(f)` — ω² 震源スペクトル（Brune のコーナー周波数）
- `G(R)` — 幾何減衰（70 km までは 1/R、以遠は `(R1/R)^p`）
- `Q(f) = Q0 · f^η` — 非弾性減衰
- `κ` — 高周波遮断

振幅スペクトルとランダム位相、Saragoni-Hart 型の時間窓から時刻歴を作り、
P 波パケットと S 波パケットを別々に合成して重ね合わせる。P 波は上下動が主、
S 波は水平動が主となるよう成分比を与える。

観測点は震源距離順にチャンク化し、各チャンク自身の P 初動に揃えた局所時間軸で
合成する。断層長に比べ十分遠いチャンクは有限断層の構造を分解できないため、
小断層の解像度は観測点までの距離に応じて落とす。小断層 1 個の代表寸法が
距離の 1/3 以下に収まれば点震源とみなしてよいため、この条件を満たす最も粗い
解像度（既定は 120 / 28 / 1 の 3 段）を選ぶ。全国 3,000〜4,000 点あたり、
内陸の M7 級で 1〜2 分、海溝型の M9 級で 15〜20 分。

震源継続時間には上限を置いている。単純に `1/fc` とすると、規模が大きいほど同じ
スペクトル振幅が長い時間に広がって最大振幅が下がり、震度の増分が規模 1 あたり
1.0 ではなく 0.5 に留まってしまう。観測点で強い揺れが続く時間は断層全体の破壊時間
ではなく近傍のアスペリティを破壊が通過する時間で決まるため、上限を置いて
この飽和を取り除く。

### パラメータの較正 — `tools/calibrate.py`

`Q0`, `η`, `κ`、遠距離の幾何減衰の指数 `p`、震源種別ごとの実効応力降下量は、
合成波形から求めた計測震度が司・翠川 (1999) + 藤本・翠川 (2005) による震度に
最も近くなるようグリッドサーチで決めた（Mw 6.0〜8.6 × 震央距離 10〜450 km）。

遠距離の減衰指数 **p = 0.65**

| 震源種別 | 実効応力降下量 | 震度の RMS 誤差 | 200 km 以遠の偏り |
|---|---|---|---|
| 地殻内 | 160 bar | 0.226 | −0.10 |
| プレート間 | 1000 bar | 0.259 | +0.02 |
| スラブ内 | 700 bar | 0.284 | −0.11 |

当初は Atkinson & Boore (1995) の三折れ線（70〜130 km で減衰なし、以遠 R^-0.5）を
使っていたが、遠方の揺れが実際より強く広がり、200 km 以遠で +0.17〜+0.32 震度の
偏りがあった。冪型に変えて指数を較正したことで、この偏りはほぼ解消している。

ω² モデルでは応力降下量はコーナー周波数 `fc = 4.9e6·β·(Δσ/M0)^(1/3)` だけに効くため、
ここでの値は観測から求まる静的応力降下量そのものではなく、**距離減衰式を再現するよう
較正した実効パラメータ**である。海溝型・スラブ内で値が大きいのは、これらの断層面が
同じ規模の地殻内地震より広く、一様すべりを仮定すると観測点近傍のすべりが薄まって
過小評価となるため。実際の大地震では高周波はアスペリティから放射されるが、
本モデルはそれを明示的に置かず、この実効値で吸収している。

### 距離減衰式の補正と異常震域 — `sim/gmpe.py`

簡易エンジンは司・翠川 (1999) をそのまま使うが、この式には 2 つ足りないものがある。

**マグニチュード依存の減り方** — 司・翠川の式は遠方の減り方がマグニチュードに
よらない形をしている。実際には小さい地震ほどコーナー周波数が高くて高周波が卓越し、
`Q(f)` による減衰が強く効くため、遠方では大きい地震より速く減る。波形合成と
距離減衰式の差を M4.5〜8.0・10〜500 km で測ると、M5 では 200 km 以遠で
0.8 震度も過大だった。次の形を当てはめて補正する（残差 RMS 0.11 計測震度）。

    Δ(M, r) = N(M) + (A(M) − N(M))·(1 − exp(−r / 55km))

`N` は震源直上の差、`A` は遠方での差で、どちらも M に対して直線、M7 あたりで
頭打ちになる。これを入れると M5.0 で 200 km 以遠が震度 0、300 km 以遠は無感となり、
実際の有感範囲と合う。

**異常震域** — 沈み込む海洋プレートは冷たく Q が高いため、スラブ内を伝わった波は
ほとんど減衰しない。一方、背弧側へ向かう波は高温のマントルウェッジ（低 Q）を
通るので強く減衰する。このため深い地震では、震央から遠い前弧側（太平洋側）の
ほうが、近い背弧側より大きく揺れる。火山フロント（千島・東北・伊豆小笠原弧）
からの東西方向の距離で前弧・背弧を判定し、深さ 70 km から効かせて 150 km で
完全に効かせる。前弧側では非弾性減衰項の 45% を打ち消す（頭打ち 2.5 震度）。

2015 年小笠原諸島西方沖の地震（M8.1・深さ 682 km）で確かめると、震央距離が
ほぼ同じ東京（875 km）と大阪（905 km）で震度 3.9 と 1.1 に分かれ、全国が
有感になる。補正前は東京 2.4・大阪 1.1 で、この差が出なかった。

### 計測震度 — `sim/jma_intensity.py`

気象庁告示「計測震度の算出方法」をそのまま実装している。

1. 3 成分の加速度をフーリエ変換する
2. 周期の効果 `sqrt(1/f)`、ハイカット（fc = 10 Hz）、ローカット（f0 = 0.5 Hz）を掛ける
3. 逆変換して 3 成分をベクトル合成する
4. 合成加速度が `a0` 以上となる時間の合計が **0.3 秒** となる `a0` を求める
5. `I = 2·log10(a0) + 0.94` を計算し、小数第 3 位を四捨五入して第 2 位を切り捨てる

リアルタイム震度（`sim/metrics.py`）は同じフィルタを掛けたうえで、直近 1 秒の窓の中で
合計 0.3 秒だけ超える振幅から求める。

### サイト増幅

J-SHIS 表層地盤モデルから取得した観測点ごとの **AVS30**（地表 30 m の平均 S 波速度）を
用い、藤本・翠川 (2006) の `log10(ARV) = 1.83 − 0.66·log10(AVS30)` で増幅率を与える。
周波数依存性は四分の一波長則による卓越周波数で表現する。

### 地震動のばらつき — `sim/variability.py`

距離減衰式もスペクトルモデルも与えるのは中央値なので、そのまま使うと震度が
#### 遠方の補正とつなぎ目

実際の観測と突き合わせると、300 km より遠くで 0.3〜0.5 ほど高く出ていた
（2011 三陸沖: 東京 380 km で 5強、大阪 770 km で 3、札幌 560 km で 3〜4 /
2024 能登沖: 東京 305 km で 3）。距離とともに効く一定の減衰
`-0.55 * (1 - exp(-r/400km))` を引いている（`gmpe.long_range_correction`）。

波形合成は震央距離 900 km までで、その外側は距離減衰式で埋める。両者の水準が
ずれていると打ち切り距離のところに不自然な円の縁ができるので、境目の内側と外側
100 km ずつの中央値が揃うように外側をずらしている。

震源距離だけで決まり、同心円の縞になる。実際の観測はすぐ隣の観測点でも
1 階級ずれることが珍しくないので、残差を足して中央値の周りに散らす。

    δ = φ_S2S·ζ(x) + φ_path·ψ(x)      （計測震度の単位）

- **観測点固有の項** `φ_S2S = 0.30` — AVS30 では説明しきれない表層の特性。
  観測点の座標から決まる固定値なので、同じ観測点は毎回同じ向きにずれる。
- **経路の項** `φ_path = 0.24` — 地震ごとに引き直す。Jayaram & Baker (2009) の
  空間相関 `ρ(h) = exp(−3h/b)`（b = 25 km）に従う。指数型の相関は
  Matérn (ν = 1/2) にあたり、その波数スペクトルは 2 次元コーシー分布になるので、
  そこから波数を引いたランダムフーリエ級数で場を作っている。

地震間の項は入れていない。断層寸法・応力降下量・破壊継続時間まで与える
震源モデルなので、地震ごとの違いはそちらで表現されるとみなす。

ばらつきは揺れが強いほど小さくする（振幅依存の σ）。地盤が非線形化して
軟弱地盤の増幅が頭打ちになるためで、Youngs et al. (1995) 以降の距離減衰式が
採り入れている性質である。震度 4 までは全量、震度 6.5 以上では 0.4 倍として
間を直線で結ぶ。

この 0.4 倍は、報告されている振幅依存性（弱震から強震で 15〜30% 程度の減少）
より強い。中央値の側に地盤の非線形性が入っておらず強震域の増幅が頭打ちに
ならないぶんを、ここで代わりに抑えているためである。これが無いと最大震度の
出る場所で残差が積み上がり、計測震度が観測記録の上限（2016 年熊本地震・
益城町の 6.7）を大きく超えてしまう（首都直下シナリオで 7.4 になった）。

波形合成では加速度を `10^(δ/2)` 倍する（計測震度が `2·log10(a0)+0.94` のため）。
簡易エンジンでは PGV を `10^(δ/1.72)` 倍する。観測点固有の項は座標のハッシュから
作っているので、Python と JavaScript で同じ値になる。

### 緊急地震速報 — `sim/eew.py`

観測点が P 波を検知した順に震源とマグニチュードを推定し直す。

- **震源決定** — 検知時刻の残差二乗和を最小にする（緯度, 経度, 深さ, 発震時）を
  段階的に細かくするグリッドサーチで求める
- **規模推定** — P 波部分の最大変位振幅と震源距離から `M = log10(A) + B·log10(R) + C`。
  経過時間が短いほど振幅が育っておらず過小評価となるため、実際の緊急地震速報と同様に
  報を重ねるごとに上方修正される
- **予測震度** — 推定震源と推定 M から距離減衰式で各地の震度を予測し、
  最大予測震度が 5 弱以上なら「警報」、3 以上なら「予報」とする

### 余震 — `sim/aftershock.py`

改良大森公式 `n(t) = K/(t+c)^p`（p = 1.08）で時間減衰、Gutenberg-Richter 則
（b = 0.9）で規模分布、Båth の法則（最大余震は本震 − 1.2）で上限を与える。
震源は本震の断層面の周囲に分布させる。

### 津波 — `sim/tsunami.py`

海域の浅い地震（深さ 60 km 以下、M6.0 以上）で発生させる。予想高さは
阿部 (1989) の `log10 H = Mt − log10(Δ) − 5.55`。

Δ は直線距離ではなく **海の上を通る最短経路の道のり**。津波は陸を突っ切らず、
岬や海峡を回り込んで伝わる。陸域マスクを 0.08°（約 9 km）に粗くし、外周から
たどり着ける海（湖や川は除く）の格子でダイクストラ法を解いて求める。直線距離で
測っていたころは、房総を回って届く静岡・高知・宮崎が「陸に遮られている」ことに
なり、M9 でも 11 予報区しか対象にならなかった。

回り込んだぶんエネルギーは散るので、`(道のり / 直線距離)^-1.2` を掛ける。
湾の奥や日本海側はこれで下がる。2011 年三陸沖 M9.0 との比較:

| 予報区 | 計算 | 実績 |
|---|---|---|
| 宮城県 | 18.4 m | 17 m |
| 岩手県 | 16.8 m | 16 m |
| 千葉県九十九里・外房 | 7.6 m | 7 m |
| 高知県 | 2.0 m | 2 m |
| 沖縄本島地方 | 1.1 m | 0.6 m |
| 東京湾内湾 | 3.6 m | 1.5 m |

外洋に面した沿岸はよく合う。東京湾・大阪湾のように奥まったところは 2〜3 倍
高めに出る（気象庁の発表も安全側に倒すので、この向きの外れ方は許容している）。
予想高さから大津波警報・津波警報・津波注意報・津波予報を割り当て、到達予想時刻は
経路の道のりと実効伝播速度・浅海での減速から求める。

## データ

すべて公開データから機械的に生成している。生成物のみをリポジトリに含め、
生データは `tools/fetch_sources.py` で再取得できる。

| データ | 出典 | 件数 |
|---|---|---|
| 震度観測点（座標つき） | 気象庁 | 4,360 点 |
| 海底地震計 (S-net・DONET 相当) | 配置は近似（`tools/build_seafloor.py`） | 201 点 |
| 細分区域 | 気象庁 電文コード表 `AreaForecastLocalE` | 188 区 |
| 震央地名 | 気象庁 電文コード表 `AreaEpicenter` | 343 件（うち代表座標を持つもの 294 件） |
| 津波予報区 | 気象庁 電文コード表 `AreaTsunami` | 66 区 |
| AVS30・微地形区分 | 防災科学技術研究所 J-SHIS | 4,277 点 |
| 標高・水深 | GMRT (Global Multi-Resolution Topography) | 1,708 x 1,421 点・約 4 km 間隔 |
| 市区町村界 | 歴史的行政区域データセットβ版 (CODH) / もとは国土数値情報 | 1,889 市区町村 |
| 細分区域と市区町村の対応 | 気象庁 電文コード表 `AreaInformationCity` | 1,914 件 |

**細分区域** — 震度速報は都道府県ではなく細分区域（宮城県北部・中部・南部など、
188 区）の単位で発表される。区域のポリゴンそのものは公開されていないが、どの市区町村から
できているかは電文コード表に載っているので、市区町村界を区域ごとに融合して作る
（`tools/build_subdivision_polygons.py`）。海岸線も内陸の境も実際の縁どおりになる。

    細分区域 = その区域に属する市区町村の和

TopoJSON の弧は隣り合う市区町村で共有されているため、弧の段階で間引けば融合しても
境界がずれない（ポリゴンごとに間引くと隙間ができる）。

市区町村界の年次と電文コード表の年次はずれることがある（2024 年の浜松市の区の
再編など）。対応表に無い市区町村は、代表点にいちばん近い震度観測点が属する区域に
入れる。地図のほうは対応表と関わりなく全市区町村から作るので、コード表が
追いついていなくても欠けない。同じ市区町村界を都道府県ごとに
融合して地図用の `japan.geojson` も作る。地図の陸と震度の塗りつぶしを別々の出典から
作ると海岸線がわずかにずれ、塗りの縁に地の色がはみ出して見えるためである。

**海底地形** — 海を一色で塗ると海溝や海盆が見えず地図が平板になるため、GMRT の
標高・水深グリッドから陰影図を焼いて背景に敷く（`tools/build_bathymetry.py`）。
ブラウザ側は経度と `mercY` について線形な投影を使っているので、Web メルカトルで
焼いておけば四隅を投影して `drawImage` するだけで位置が合う。日本の陸は
GeoJSON のポリゴンで上から塗るため、この画像の陸は朝鮮半島・沿海州・中国大陸など
周辺の陸地を出すために使う。

**震央地名の判定** — 陸域マスク（都道府県界を 0.01° 格子にラスタ化したもの）で
陸か海かを判定し、陸域は最近傍の震度観測点が属する区分、海域は最近傍の海域アンカーが
属する区分を採る。離島の「〜近海」は島の観測点の重心を海域アンカーにも登録する。
気象庁の区域ポリゴンは公開されていないため、この最近傍法による近似である。

起動しただけでは地震を起こさない。設定モードで震源を決めるか、保存済みシナリオを
選んだときに再生が始まる。

python scripts/run_scenario.py scenarios/nankai_trough.json

## スマートフォン

画面が狭いときはレイアウトを切り替える。

- **縦向き（幅 720px 以下）** — 地図を上、パネルを下からのシートにする。アイコン列は
  シートの上端に横並びで置き、右端の ▾ でシートをたたむと地図が全画面になる。
  再生バー・凡例・ズームは地図に重ねる。文字と余白も詰める。
- **横向き（高さ 540px 以下）** — 左パネルのまま幅と文字を詰め、観測波形を隠す。

地図の canvas は表示領域から実寸を測り直すので、シートの開閉と画面の回転で
測り直しを走らせている。

## 音源

効果音は WebAudio による合成音を同梱している。手元のファイルに差し替える場合は
`web/sounds/` に置き、`manifest.json` で対応づける（`web/sounds/README.md`）。
このディレクトリは Git の管理対象外で、リポジトリには合成音の生成コードのみが入る。
`tools/build_bundle.py --sounds` を付けると単一 HTML にも埋め込める。

差し替えできるのは、緊急地震速報の第1報・続報（震源やマグニチュードが大きく
動いた報は別扱い）・地震情報の 3 段階・津波の 5 種・秒読みと、観測点の反応 7 段
（`new_int_0` 〜 `new_int_6`）。反応の段は揺れの最大 PGA が
0.2 / 0.5 / 2 / 5 / 20 / 150 / 500 gal を越えるたびに一度ずつ鳴り、PGA の配色と
対応している。

### 地震情報の読み上げ

地震情報は、効果音が鳴り終わってから合成音声で読み上げる。声は Scratch の
音声合成の「ネズミ」（アルト ja-JP を 1.19 倍の速さで再生したもの）で、
`web/sounds/voice/` に置いた短いクリップをつないで喋らせる。

```bash
python tools/generate_voice.py --scope core   # 定型句・震度・数値のみ (186 語)
python tools/generate_voice.py                # 震央地名・震度観測地域名も含む (668 語)
python tools/generate_voice.py --dry-run      # 読み上げ文の一覧だけ見る
```

読み上げるのは次の場面。

| 場面 | 原稿 |
| --- | --- |
| 揺れの検知 | 千葉県南部で揺れを検出。 |
| 震度速報 (VXSE51) | 震度速報。最大震度6強を。宮城県北部。で観測しました。 |
| 確定・津波なし | 地震情報。午後3時47分頃、最大震度6強を観測する地震がありました。この地震による津波の心配はありません。震源地は、宮城県沖。深さ60キロメートル。地震の規模を示すマグニチュードは、7.3と、推定されています。 |
| 確定・津波発表中 | （同上、津波の一文が）現在、津波予報等を発表中です。 |
| 津波警報・大津波警報 | 大津波警報が次の地域に発表されています。直ちに避難してください。宮城県。以上の地域で、予想される津波の高さは、10メートル以上です。**また、**津波注意報が、次の地域に発表されています。…（段ごとに繰り返す）**震源に関する情報。**震源地は、宮城県沖。深さ20キロメートル。地震の規模を示すマグニチュードは、9.0と、推定されています。現在、大津波警報等を発表中です。海岸からは直ちに離れてください。 |
| 津波注意報 | 津波注意報が次の地域に発表されています。…以上の地域で、予想される津波の高さは、1メートルです。海の中や海岸から離れてください。 |
| 津波予報 | （効果音だけ。読み上げなし） |

津波の読み上げは、発表の段（大津波警報 → 津波警報 → 津波注意報）ごとにまとめ、
強いものから読む。読み上げる予報区は 1 段につき高いほうから 8 区まで。

揺れの検知は、最初に反応した細分区域を一度だけ読む。揺れが隣へ広がっていくたびには
読まず、既に反応しているどの区域からも 250 km 以上離れたところで同時に反応が出たとき
だけ読み直す（日向灘 M7.8 の例では、宮崎県南部平野部・沖縄県大東島・小笠原の 3 回）。

震央地名・震度観測地域名・震度・時刻・深さ・マグニチュードはすべて部品として
持っているので、設定モードで決めた任意の震源についても読み上げられる。
クリップが無いときはブラウザ内蔵の音声合成（Web Speech API）に落ちる。
単一 HTML へは `tools/build_bundle.py --voice` で埋め込む。生成した音声は
差し替え音源と同じく Git の管理対象外。

## 制限

- 気象庁の震央地名・細分区域のポリゴンは公開されていないため、最近傍法で近似している
- 遠距離の幾何減衰の指数は経験式に合わせた較正値で、地域ごとの違いは扱わない
- 有限断層は一様すべりを仮定しており、アスペリティを置いていない。
  その影響は震源種別ごとの実効応力降下量で吸収している
- 異常震域は火山フロントからの距離による近似で、スラブの形そのものは扱っていない。
  フィリピン海プレート側の前弧・背弧は区別していない
- 表層地盤の増幅は AVS30 に基づく経験式で、地盤の非線形性を考慮していない。
  そのぶんを振幅依存の σ を強めに掛けて抑えているが、本来は中央値側で扱うべきもの
- 残差の標準偏差は全国一律で、地域差や規模・距離への依存は入れていない
- 津波は伝播計算ではなく経験式と陸域による遮蔽判定で、遡上や湾内の増幅は扱わない
- 長周期地震動階級は PGV からの概算
