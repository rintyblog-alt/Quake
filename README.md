# seismic-sim

日本全国の地震動シミュレータと地震モニタ。

震源パラメータを与えると、気象庁の震度観測点 4,360 点における地震動を合成し、
リアルタイム震度の時系列・計測震度・緊急地震速報の発表列・余震活動・津波予報を
生成する。結果はブラウザ上の地震モニタで時系列に再生できる。

## できること

| | |
|---|---|
| **視覚モード** | 震源からの P/S 波の広がり、観測点ごとのリアルタイム震度、緊急地震速報の第1報〜最終報、揺れが収まったあとの確定震度、余震の連続発生、津波警報を時系列で再生する |
| **設定モード** | 地図をクリックして震源・規模・深さ・断層パラメータを指定し、その場で計算する。余震・津波・緊急地震速報の有無も切り替えられる |
| **地震情報** | 最大震度・震源地・マグニチュード・深さを表示。直近 5 件はクリックで再生でき、履歴は 15 件まで残る |

観測点の表示は **震度の数字入りの円** と **色だけの円**（強震モニタ風の連続配色）を
切り替えられる。

## 2 つの計算エンジン

同じ物理を、精度と速度の違う 2 通りで実装している。

**Python（高精度・オフライン）** — 確率論的地震動合成で 3 成分の加速度波形を作り、
気象庁告示どおりの手順で計測震度を算出する。1 シナリオあたり数分。
`scripts/run_scenario.py` で計算し、結果を JSON に書き出して再生する。

**JavaScript（簡易・その場で計算）** — 距離減衰式で震度分布を求め、走時表から
到達時刻を引く。設定モードで指定した震源を待たずに再生できる。

両者は震度分布と到達時刻で整合するよう較正してある。

## 物理モデル

### 走時 — `sim/velocity.py`

JMA2001 に準じた 1 次元速度構造（深さ 0〜700 km、Vp/Vs = 1.73）を薄層に分割し、
レイパラメータ p を掃引して走時曲線を作る。各層で

```
eta = sqrt(1/v² - p²)        鉛直スローネス
dX  = p · dz / eta           水平距離の増分
dT  = dz / (v² · eta)        走時の増分
```

を積み上げる。レイは `v(z) = 1/p` となる深さで反転する。上向き直達波と
下向き反転波の 2 つの枝を計算し、同じ震央距離に複数の到達がある場合は
最小走時（初動）を採る。速度の不連続は制御点間を線形補間して連続勾配に均し、
head wave を turning ray として取り込む。

深さ 10 km・震央距離 100 km で P 波 16.3 秒、S-P 時間 11.9 秒。

### 震源 — `sim/source.py`

モーメントマグニチュードから地震モーメント `M0 = 10^(1.5·Mw + 9.1)` [N·m] を求め、
断層面積は地殻内・スラブ内で入倉・三宅 (2001)、プレート間で Murotani et al. (2008)
系のスケーリング則による。幅は地震発生層の厚さで頭打ちにする。断層面は走向・傾斜を
持つ矩形として小断層に分割し、破壊開始点からの距離を破壊伝播速度（0.72 Vs）で
割った時間を各小断層の破壊時刻とする。

### 地震動の合成 — `sim/stochastic.py`

Boore の stochastic method。各小断層について

```
A(f) = C · S(f) · G(R) · exp(−π f R / (Q(f) v)) · Amp_site(f) · exp(−π κ f)
```

- `S(f)` — ω² 震源スペクトル（Brune のコーナー周波数）
- `G(R)` — 三折れ線の幾何減衰（〜70 km で 1/R、70〜130 km で一定、以遠で R^-0.5）
- `Q(f) = Q0 · f^η` — 非弾性減衰
- `κ` — 高周波遮断

振幅スペクトルとランダム位相、Saragoni-Hart 型の時間窓から時刻歴を作り、
P 波パケットと S 波パケットを別々に合成して重ね合わせる。P 波は上下動が主、
S 波は水平動が主となるよう成分比を与える。

観測点は震源距離順にチャンク化し、各チャンク自身の P 初動に揃えた局所時間軸で
合成する。断層長に比べ十分遠いチャンクは有限断層の構造を分解できないため、
モーメント重心に置いた等価点震源に縮約する。全国 3,000〜4,000 点で 2〜4 分。

**経路パラメータの較正** — `Q0`, `η`, `κ` は `tools/calibrate.py` により、
合成波形から求めた計測震度が司・翠川 (1999) + 藤本・翠川 (2005) による震度に
最も近くなるよう決めた（Mw 6.0〜7.5 × 震央距離 10〜300 km で**震度の RMS 誤差 0.25**）。

### 計測震度 — `sim/jma_intensity.py`

気象庁告示「計測震度の算出方法」をそのまま実装している。

1. 3 成分の加速度をフーリエ変換する
2. 周期の効果 `sqrt(1/f)`、ハイカット（fc = 10 Hz）、ローカット（f0 = 0.5 Hz）を掛ける
3. 逆変換して 3 成分をベクトル合成する
4. 合成加速度が `a0` 以上となる時間の合計が **0.3 秒** となる `a0` を求める
5. `I = 2·log10(a0) + 0.94` を計算し、小数第 3 位を四捨五入して第 2 位を切り捨てる

リアルタイム震度（`sim/metrics.py`）は同じフィルタを掛けたうえで、直近 1 秒の窓の中で
合計 0.3 秒だけ超える振幅から求める。

### サイト増幅

J-SHIS 表層地盤モデルから取得した観測点ごとの **AVS30**（地表 30 m の平均 S 波速度）を
用い、藤本・翠川 (2006) の `log10(ARV) = 1.83 − 0.66·log10(AVS30)` で増幅率を与える。
周波数依存性は四分の一波長則による卓越周波数で表現する。

### 緊急地震速報 — `sim/eew.py`

観測点が P 波を検知した順に震源とマグニチュードを推定し直す。

- **震源決定** — 検知時刻の残差二乗和を最小にする（緯度, 経度, 深さ, 発震時）を
  段階的に細かくするグリッドサーチで求める
- **規模推定** — P 波部分の最大変位振幅と震源距離から `M = log10(A) + B·log10(R) + C`。
  経過時間が短いほど振幅が育っておらず過小評価となるため、実際の緊急地震速報と同様に
  報を重ねるごとに上方修正される
- **予測震度** — 推定震源と推定 M から距離減衰式で各地の震度を予測し、
  最大予測震度が 5 弱以上なら「警報」、3 以上なら「予報」とする

### 余震 — `sim/aftershock.py`

改良大森公式 `n(t) = K/(t+c)^p`（p = 1.08）で時間減衰、Gutenberg-Richter 則
（b = 0.9）で規模分布、Båth の法則（最大余震は本震 − 1.2）で上限を与える。
震源は本震の断層面の周囲に分布させる。

### 津波 — `sim/tsunami.py`

海域の浅い地震（深さ 60 km 以下、M6.0 以上）で発生させる。予想高さは
阿部 (1989) の `log10 H = Mt − log10(Δ) − 5.55`。遠距離では追加の減衰を掛け、
**震源から沿岸までの経路が陸域を横切る予報区は遮蔽されるものとして除外する**
（陸域マスクによる判定）。予想高さから大津波警報・津波警報・津波注意報・津波予報を
割り当て、到達予想時刻は実効伝播速度と浅海での減速から求める。

## データ

すべて公開データから機械的に生成している。生成物のみをリポジトリに含め、
生データは `tools/fetch_sources.py` で再取得できる。

| データ | 出典 | 件数 |
|---|---|---|
| 震度観測点（座標つき） | 気象庁 | 4,360 点 |
| 震央地名 | 気象庁 電文コード表 `AreaEpicenter` | 343 件（うち代表座標を持つもの 294 件） |
| 津波予報区 | 気象庁 電文コード表 `AreaTsunami` | 66 区 |
| AVS30・微地形区分 | 防災科学技術研究所 J-SHIS | 4,277 点 |
| 都道府県界 | dataofjapan/land | 47 都道府県・48,509 頂点 |

**震央地名の判定** — 陸域マスク（都道府県界を 0.01° 格子にラスタ化したもの）で
陸か海かを判定し、陸域は最近傍の震度観測点が属する区分、海域は最近傍の海域アンカーが
属する区分を採る。離島の「〜近海」は島の観測点の重心を海域アンカーにも登録する。
気象庁の区域ポリゴンは公開されていないため、この最近傍法による近似である。

## 使い方

### 準備

```bash
pip install -r requirements.txt

python tools/fetch_sources.py     # 生データの取得
python tools/fetch_avs30.py       # J-SHIS から AVS30 を取得 (4,360 点・数分)
python tools/build_all.py         # データセットの生成
```

### 表示する

```bash
cd web && python -m http.server 8000
# http://localhost:8000 を開く
```

サーバーを立てずに開きたい場合は、単一 HTML にまとめたビルドを作る。

```bash
python tools/build_bundle.py --scenarios tokyo_bay_north
# dist/seismic-sim.html をブラウザで開く
```

### シナリオを計算する

```bash
python scripts/run_scenario.py scenarios/nankai_trough.json
python scripts/run_scenario.py --all
python scripts/run_scenario.py --lat 35.6 --lon 139.7 --depth 20 --magnitude 7.3
```

`scenarios/*.json` に定義を置く。

```json
{
  "name": "南海トラフ巨大地震（紀伊半島沖）",
  "lat": 33.10, "lon": 136.20, "depth_km": 20.0, "magnitude": 8.6,
  "kind": "interplate", "strike": 250.0, "dip": 12.0, "rake": 90.0,
  "timeline_seconds": 300.0, "aftershock_days": 3.0, "seed": 20260401
}
```

`kind` は `crustal`（地殻内）/ `interplate`（プレート間）/ `intraslab`（スラブ内）。

### 経路パラメータを較正し直す

```bash
python tools/calibrate.py          # グリッドサーチ (数十分)
python tools/calibrate.py --quick  # 粗いグリッド
```

### テスト

```bash
python -m pytest tests/ -q
```

## 制限

- 気象庁の震央地名・細分区域のポリゴンは公開されていないため、最近傍法で近似している
- 有限断層は一様すべりを仮定しており、アスペリティを置いていない
- 表層地盤の増幅は AVS30 に基づく経験式で、地盤の非線形性を考慮していない
- 津波は伝播計算ではなく経験式と陸域による遮蔽判定で、遡上や湾内の増幅は扱わない
- 長周期地震動階級は PGV からの概算
